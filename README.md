# Billing & Receivables Studio

An offline browser application for maintaining clients and services, creating itemized invoices, recording payments, and monitoring receivables. This public edition is adapted from the original Aligh Nexus billing application. Records are stored in the browser.

## Run locally

Select **Code → Download ZIP**, extract the archive, and open `index.html` in your browser. Use fictional data for the example below.

1. Create a client and a service.
2. Create an invoice for a total of 300.
3. Record a payment of 120 and confirm that 180 remains outstanding.
4. Record the final 180 and confirm that the invoice is paid.
